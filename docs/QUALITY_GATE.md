# Quality Gate Checklist

Before accepting a calibration commit:

- [ ] one explicit hypothesis
- [ ] no unrelated changes
- [ ] complete tests pass
- [ ] fast validation passes
- [ ] runtime below ten minutes
- [ ] all five archetypes reviewed
- [ ] no unexplained regression
- [ ] branch head rechecked
- [ ] no active conflicting CI
- [ ] workflow run ID verified
- [ ] logbook updated
