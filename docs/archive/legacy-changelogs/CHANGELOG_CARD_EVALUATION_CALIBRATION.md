# Card Evaluation Calibration

- Differentiates card replacement, card selection and true card advantage.
- Values exile, destroy, counter, bounce and damage interaction separately.
- Accounts for interaction speed, mana cost and conditional restrictions.
- Improves ETB, repeatable-effect, token and creature-keyword evaluation.
- Penalizes weak vanilla creatures, narrow effects and combat tricks.
- Refines expensive-card penalties based on actual immediate impact.
- Adds focused regression tests for common card-evaluation mistakes.
