# Calibration Guide

The operational rules are intentionally split:

- `SPECIFICATION.md` defines stable development rules.
- `PROMPTS/global-calibration.md` defines the executable calibration procedure.
- `DEVELOPMENT_LOGBOOK.md` stores chronological learning.
- `ROADMAP.md` stores priorities.
- `DECISIONS.md` stores durable decisions.
- `KNOWN_ISSUES.md` stores confirmed and open problems.
- `META.md` stores reference knowledge.

A chat instruction should reference these files instead of duplicating them. Changes to the specification require an entry in `CHANGELOG_SPECIFICATION.md`.
